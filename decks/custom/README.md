# Experimental custom Center Decks

These 100 shared-market environments are experimental designs, not a balance-tested ranking. Every player still starts with 8 Hacker and 2 Attack.

To import, copy a file's `code` into **Decks → Import**, or open the `.phreakdeck.json` file in the deck importer. Descriptions, play guidance, and combos are included in each file. Card names in combo notes are enclosed in backticks; either printing's display name identifies the same base card, except Mognet has its own rules.

Rebuild with `godot4.7.1 --headless -s tools/custom_decks_build.gd`. Source: `tools/custom_deck_specs.json`, generated from the hand-written designs in `tools/custom_decks/deck_defs.py` by `tools/custom_decks/design.py` (see its header).
